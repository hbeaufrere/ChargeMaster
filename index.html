Set up GitHub auto-sync

How to get a token:
  1. Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it (e.g. "Chargemaster app"). Resource owner = your account. Repository access = "Only select repositories" → pick this repo.
  3. Under Repository permissions, set Contents: Read and write.
  4. Generate, copy the token (starts with github_pat_…), and paste below.
